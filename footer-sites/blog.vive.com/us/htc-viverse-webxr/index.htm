HTC VIVERSE là một công cụ hỗ trợ WebXR cho Android

VIVERSE Team • 2025-06-18
Chia sẻ

產品消息 | Metaverse 元宇宙

5 phút đọc

HTC旗下3D 沉浸式網路生態VIVERSE，今（16）日宣布 VIVERSE Worlds 即日起全面支援全球各大線上主流 WebXR 遊戲引擎，打造開放創作環境，成為全球領先的沉浸式3D 內容創建平台。

隨著沉浸式敘事與內容創作市場預估於 2030 年攀升至 580 億美元，業界對於一個開放且不依賴特定遊戲引擎的平台需求日益迫切。VIVERSE 為目前唯一無需專屬工具，即可支援最廣泛的遊戲引擎開發的平台，成為全球 3D 內容託管與探索的首選據點。無論是專業開發者或無程式基礎的創作者，皆可透過 VIVERSE 輕鬆建構、部署並呈現沉浸式體驗，加速邁向開放網路的 3D 創作時代。

 

全面支援主流 WebXR 遊戲引擎 推動開放且跨平台多元創作生態

此次重大更新讓開發者能透過自身熟悉的引擎,無縫將遊戲、互動體驗等 3D 內容部署至 VIVERSE Worlds——這個專為線上展示與分享 3D 沉浸式內容而設計的開放平台。VIVERSE Worlds 平台現已全面支援 Unity WebGL、Three.js、React-Three-Fiber、PlayCanvas、Babylon.js、A-Frame、Godot 等主流 WebXR 開發工具平台，並積極拓展與擁有專有技術如 Niantic 8th Wall 與 Wonderland 等平台的合作機會，持續強化跨平台創作生態的整合力與創新應用。

VIVERSE 自今年 2 月推出整合性VIVERSE Worlds 以來，已吸引全球 3D 創作者投入內容創作，並透過平台獲得合理報酬。多位遊戲引擎產業領袖亦對 VIVERSE Worlds 的最新進展表示高度肯定：

首先，資深Three.js 與 React-Three-Fiber 的開發者 Bela Bohlender 表示：「VIVERSE 團隊深刻理解開放式3D沉浸式網路的潛力，並迅速構建出支持創作者實現願景的平台與技術架構。我也將致力於將這些機會帶給 three.js 與 R3F 的開發者社群。」

知名WebXR 遊戲引擎Wonderland Engine 的負責人 Jonathan Hale 則表示：「我們很榮幸能支持 VIVERSE 多元創作者生態，透過 Wonderland Engine 的效能優勢，協助開發者跨越瓶頸，無需受限於技術限制，專注於創新與內容創作。」

 

推出 VIVERSE Studio 與 CLI 工具　一站式部署與內容管理介面

此外，VIVERSE 並推出一套簡化操作流程的整合式後台工具 VIVERSE Studio，為創作者提供上傳、管理與追蹤 3D 內容的一站式平台。創作者在完成空間設計與建構後，可將自行製作的 WebXR 專案打包為 ZIP 檔上傳，即可輕鬆發佈至 VIVERSE。透過全新推出的 VIVERSE CLI 命令列工具（Command Line Interface Tool），亦可直接從桌面終端機、AI 工具或 CICD 部署流程進行上傳。無論使用何種基於 WebGL技術的遊戲引擎，皆可無縫支援，並可於同一介面即時掌握觀看次數、互動長短等關鍵數據。

VIVERSE 亦同步推出可支援各類開發引擎的免費遊戲服務 SDK 測試版，內建帳號系統、虛擬角色、排行榜、配對機制與網路連線功能，後續將持續擴充更多元服務。開發者可透過 VIVERSE Studio 直接取得 SDK 金鑰與應用程式 ID來進行整合開發。

此外，VIVERSE Studio 亦新增進階個人化頁面功能，支援自訂橫幅、個人頭像、簡介文字、社群連結與影片上傳，方便創作者展示內容與預告片，提升品牌經營與互動效益。

 

深耕開源社群 給予開發者充分的創作自由

VIVERSE 深知開源社群（Open Source Community）在推動沉浸式網路創新中扮演關鍵角色。為進一步強化對創作者的支持，VIVERSE Worlds 宣布正式贊助多項核心開源專案，包括 Three.js 與 React-Three-Fiber。透過實質資源挹注，VIVERSE 將協助這些關鍵技術工具持續優化與發展，進一步提升與平台的整合效率，強化創作者於 VIVERSE 上構建內容的能力。

 

HTC VIVERSE 成長事業部負責人 Andranik Aslanyan 表示：「我們的核心使命是提供開放且中立的開發環境，讓創作者能自由選擇最適合的引擎、工具與部署方式。我們持續積極支持開源社群，並深信唯有給予開發者充分的創作自由，沉浸式 3D 內容的應用才能真正普及。」
