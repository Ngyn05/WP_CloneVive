Setting up the headsets

Use VIVE Business+ to set up your headsets for the tracking mode you want to use.
  • LBE Mode
  • 3DoF Mode
  • Visual Odometry (VO) Mode
  • LBE Hybrid Mode
  • Passenger Mode
  • Simulator VR Mode
Important: Before getting started, make sure to do the following:
  • Update the system software on the headsets to the latest version, or install a specialized system package provided by HTC.
  • Connect your computer and the headsets to the same Wi‍-Fi network.
  • Set up a regular wireless access point to use as an intranet. Mobile hotspots cannot be used.

All the below steps are performed in VIVE Business+. All references to documentation are in the VIVE Business+ User Guide.

  1. Enroll the headsets you plan to use. See Enrolling devices. .
  2. Create a batch configuration package for your headsets. See Creating a batch configuration package.
    Note: Make sure LBE Mode or LBE Hybrid Mode is selected as the tracking mode. You can check the tracking mode in VIVE Business+ in Settings > Advanced > Tracking mode.
  3. Create a group. See Creating groups.
  4. Assign the configuration package to the group. See Editing group settings.
  5. Assign the headsets to the group you assigned the configuration package to. See Adding devices to a group.. The configuration package will be automatically pushed to the headsets over Wi-Fi.
