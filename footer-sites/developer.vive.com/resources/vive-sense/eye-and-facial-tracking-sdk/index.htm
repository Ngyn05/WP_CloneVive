VIVE OpenXR - All-in-One/PCVR

OpenXR  for VIVE

OpenXR enables XR portability across hardware VR devices to help developers prioritize content creation over porting. VIVE OpenXR SDK provides comprehensive support for HTC VR devices, allowing developers to build All-in-One and PCVR content with Unity and Unreal engine on HTC VR devices, including VIVE Focus Series and VIVE XR Elite . HTC’s VIVE hardware VR devices passed the Khronos group’s conformance tests, adding HTC to the growing list of official OpenXR adopters.

For details, visit https://www.khronos.org/conformance/adopters/conformant-products/openxr .

To learn more about using OpenXR to develop VR applications, consult the OpenXR 1.0 specifications, API reference documentation, and quick reference guide, all of which are available at https://www.khronos.org/OpenXR/.

How to Get Started

To get started with development, download the latest version of OpenXR for Unity and Unreal .

You can also visit the VIVE Community Forum for additional support.
